# check.sh check 12's exemption file -- the owner's D51, README gap 2130.
#
# `reach.py`'s header is the specification.  THE PROPERTY it gates: every `def` and
# `abbrev` of the library for which the compiler EMITS code -- a C function, or a
# `LEAN_EXPORT lean_object* <sym>;` GLOBAL, which is how it writes a nullary definition whose body is a
# closed constant -- must be reachable from `tm_kernel_call`, the one symbol the host
# dials, OVER THE SECTIONS `tm/src` ACTUALLY SENDS.  This file is the exceptions, and it
# is W-27's shape -- AN ENUMERATION YOU JOIN TO BE EXEMPT, NOT TO BE COVERED.
#
# THE ROOT WAS ASSUMED UNTIL W-32 (README gap 2229), and the last five words of that
# property are the repair.  `tm_kernel_call` is a DOOR, not a caller: what comes through
# it is a request whose top-level keys choose which of the kernel's sections runs, and a
# section nothing sends is a door into a room nobody enters.  `sections.py` measures
# both sides and cuts the arms no request takes; 289 definitions that this file did not
# name on 2026-09-25 -- the whole of §8.2's day planner, W-24's row renderer, and their
# decoders -- moved from reachable to unreachable when the root stopped being assumed,
# and they are the fourteen dated sections at the end of this file.
#
# THE RATCHET, AND IT IS A GATE NOW AND NOT THIS PARAGRAPH (W-31 repair, gap 2259).
# It may only SHRINK.  An entry whose definition becomes reachable, stops being emitted
# or stops existing FAILS check 12 and must be deleted in the same edit; a definition
# that becomes unreachable and is not named here fails it too.  What was missing until
# the repair is the comparand: `reach.py` checked only that the `EXEMPT` line equalled
# the entry count -- a number held against ITSELF -- so this file went 952 -> 953 in the
# very run that landed it, by one line appended to an existing section with the count
# bumped beside it, and every gate stayed green.  The comparand is now the file as
# COMMITTED AT HEAD: a new entry must sit under a section heading that is new too, and a
# new heading's reason must carry an ISO DATE.  Adding a line to an existing section
# FAILS.  Growth is a dated section in the diff, not a digit in it.  What no gate can
# read is whether a new section's reason is TRUE; that is still a reader's job, and what
# the ratchet buys is that growth costs a heading and a date instead of a character.
#
# WHAT THE SECTIONS ARE.  A `## <Module.lean> -- <reason>` line opens one, and every
# entry under it inherits its reason; an entry may add a note of its own after a `#`.
# A section without a reason, an entry under no section, and a section holding no entry
# all FAIL.  A module may have MORE THAN ONE section -- which is how a gate WIDENING
# grandfathers a module that already has one -- and an entry inherits the reason of the
# heading it stands under and of no other.  It used not to: the parser kept one reason
# per MODULE and every later heading silently overwrote it, so a second `## Emit.lean`
# heading anywhere in the file rewrote the reason all four of Emit.lean's entries
# carried, with no complaint and no change to the section count (driven; gap 2259).
#
# WHAT THIS FILE IS HONEST ABOUT.  The entries here are a GRANDFATHERED SET -- the
# definitions that were unreachable on 2026-09-25, when the gate landed at W-31 and
# when the same day's repair widened its population from 2,365 to 2,926 -- and
# most of them have not been adjudicated one by one; the sections say which have.  That is the whole point of the
# ratchet: the file is the list of definitions nobody has yet had to justify, and it can
# only get shorter.  Three of its sections are findings this campaign already carries by
# name (`Tree.lean`/D52, `Recur.lean`/gap 501, `Capacity.lean`'s `Tm.edf` pair), and the
# rest is the work of finding out which of the others are the same thing.
#
# A `(load-time)` note means the definition IS run, by a hoisted closed constant's
# initialiser at library load, and is unreachable only from the export.
# `callgraph.closed_users` measures that class on every run rather than asserting it,
# and check 12's summary line prints how many entries carry the note -- so the number
# lives in one place, which is what §5.11 asks of every number in this repository.
