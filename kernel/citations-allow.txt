# check.sh check 8's allow-list (D39, README gap 779).  `citations.py`'s own header is the
# specification; this file is the exemptions, and NOTHING in it is a pattern — every entry is
# a literal name, because a regex that silenced a class is how this check would get quietly
# useless: the next stale citation would land inside the silenced class.
#
# Two syntaxes, and four sections that mean four different things.
#
#   name          uncounted.  Cite it as often as the prose likes.
#   N name        counted.  At most N occurrences across everything swept.  Fewer is fine;
#                 more FAILS, so a NEW sentence reaching for one of these shows up in a diff.
#
# To cite a counted name once more, the honest moves are: open it, and either move it up to
# VOCABULARY with a reason, or fix the sentence.  Bumping N without looking is how this file
# stops being worth reading.
#
# AND THE CONVENTION THAT KEEPS THIS FILE SMALL.  When a sentence records that a name is
# DEAD — refuted, renamed, deleted — write the dead name WITHOUT backticks.  It is then not
# swept, it needs no entry here, and a later sentence that cites it as though it were alive
# still fails.  W-19 found this by inverting its own repair: the three names it had just
# corrected were backticked in the correcting sentence, which put them on this list, which
# would have let the very citations it repaired come back with the check still green.
